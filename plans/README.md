# Work-in-progress plans

Plans for ongoing work, written so that the work can continue across machines and sessions. The plans may be deleted when they are considered completly done, but generally kept while there are still open questions. A list of the current plans are given below.

- [lifting_line_correction_upgrade.md](lifting_line_correction_upgrade.md): self-induced vs
  other-induced velocities in the lifting line wakes, and new wake types for the lifting line
  correction in actuator line simulations, including a dynamic wake with an interface to the CFD
  solvers.
- [known_missing_features.md](known_missing_features.md): known issues and missing features that
  are deferred to later versions, with ideas for the fixes.
