# A C-interface for the Stormbird library

This crate implements a simple C-interface to the main structures and methods in the Stormbird library. The available functionality is intended to be very similar to what is available in the pystormbird crate, but implement to be used through a C-ABI. This mainly so that library can be interfaced by other languages without their dedicated stormbird interface. In other words, as most languages understand the C-ABI, a general C interface might be useful.

The header file, `include/cstormbird.h`, is generated by `cbindgen` when the crate is built.

## Conventions

Rust structures that cannot be represented directly over a C-ABI, because they contain enums with data or variable sized data, are handled as *opaque handles*. These are `CompleteSailModel`, `WindCondition` and `SimulationResult`. A handle is created by one of the `*_new_*` functions, which return `NULL` on failure, and must be released with the matching `*_drop` function.

Functions that return a value use the natural type, and return `NaN` for a null pointer input. The remaining functions return an `int32_t`, which is either the number of elements written to an output array, or one of the following:

| Code | Meaning                                                              |
|------|----------------------------------------------------------------------|
| `0`  | Success, for functions that do not return a count                      |
| `-1` | One of the input pointers is null                                      |
| `-2` | An array length is zero, or does not match what the model expects      |
| `-3` | A string is not valid UTF-8, or not valid JSON for the given structure |
| `-4` | The wind condition does not use the velocity variation that is needed  |
| `-5` | The operation is not available for this simulation configuration       |

Arrays are always owned by the caller. Vectors are passed as 3 doubles per point.

## Error messages

The error codes say *that* something went wrong, and `stormbird_last_error_message` says *what*. It returns a description of the most recent failed call on the calling thread, or `NULL` if nothing has failed yet, and should only be read after a function has reported a failure. Successful calls leave it untouched. The string is owned by the library and is only valid until the next failing call on the same thread, so copy it if it is needed after that. `stormbird_clear_last_error` resets it.

```c
CompleteSailModel *model = complete_sail_model_new(setup_json_string);

if (model == NULL) {
    fprintf(stderr, "Could not build the sail model: %s\n", stormbird_last_error_message());
    return 1;
}
```

## The two entry points

`CompleteSailModel` combines a lifting line simulation with a wind environment and a controller, and is the interface to use when the sails should be simulated as a complete system. `LiftingLineSimulation` is the lifting line simulation on its own, for the cases where the freestream velocity is computed elsewhere, such as by a CFD solver. It is stepped forward in time with `lifting_line_simulation_do_step`, which needs the freestream velocity at the points given by `lifting_line_simulation_get_freestream_velocity_points`. With a dynamic wake that set of points grows as the wake develops, so it must be queried before each time step.

```c
LiftingLineSimulation *simulation = lifting_line_simulation_new(setup_json_string);

double angles[1] = {0.17};
lifting_line_simulation_set_local_wing_angles(simulation, angles, 1);

int nr_points = lifting_line_simulation_get_number_of_freestream_velocity_points(simulation);
double *freestream = malloc(3 * nr_points * sizeof(double));
/* fill in the freestream velocity at each point, 3 doubles per point */

SimulationResult *result = lifting_line_simulation_do_step(
    simulation, time, time_step, freestream, nr_points
);

double force[3];
simulation_result_integrated_forces_sum(result, force);

simulation_result_drop(result);
free(freestream);
lifting_line_simulation_drop(simulation);
```

## Example

```c
#include "cstormbird.h"

CompleteSailModel *model = complete_sail_model_new(setup_json_string);
WindCondition *wind = wind_condition_new_power_model_with_default_shape(1.57, 10.0);

int nr_sails = complete_sail_model_get_number_of_sails(model);
SingleSailResult *results = malloc(nr_sails * sizeof(SingleSailResult));

complete_sail_model_simulate_steady_state_condition_simple_output(
    model, wind, 5.0, 1.0, results, nr_sails
);

free(results);
wind_condition_drop(wind);
complete_sail_model_drop(model);
```
